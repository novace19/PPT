      public static boolean interval(int odkud, int kam, int value)
      Ověří příslušnost do otevřeného intervalu (odkud, kam).
      Parameters:
      odkud - dolní mez, nezahrnutá

      Returns:

    • vzorkySestupně

      public double[] vzorkySestupně(double kam, double odkud, double krok)
      Generuje hodnoty odkud, odkud-krok, ... až po hodnotu nejméně kam. Zachovává pořadí parametrů ze zadání: nejprve kam, potom odkud. Dolní mez se zahrne pouze tehdy, pokud na ni vyjde přesný počet kroků. Výpočet používá desetinnou reprezentaci vstupů, nikoli opakované double odčítání.
      Parameters:
      kam - dolní mez včetně, je-li dosažitelná
      odkud - horní mez včetně
      krok - kladná konečná velikost kroku
      Returns:
      sestupné pole; při shodných mezích jednoprvkové
      Throws:
      IllegalArgumentException - pokud vstup není konečný, krok není kladný, odkud je menší než kam, vzniklo by více než milion vzorků nebo double nedokáže rozlišit sousední vzorky
